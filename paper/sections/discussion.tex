\subsection{RQ1 Interpretation: Signal Localization}
\label{sec:discussion-rq1}

\begin{figure}[htbp]
  \centering
  \includegraphics[width=\columnwidth]{fig5_saliency.png}
  \caption{Saliency map for \speck at 5 rounds.
  Bits 14--15 (MSB of $C_L \oplus C'_L$ difference) and bits 28--30 (corresponding position in $C_R \oplus C'_R$) carry the highest gradient magnitude, confirming that signal concentrates in XOR-difference channels.}
  \label{fig:saliency}
\end{figure}

\begin{figure*}[htbp]
  \centering
  \includegraphics[width=\textwidth]{fig6_attention.png}
  \caption{Attention interpretability for \speck (E19).
  \emph{Left:} Bit importance heatmap across rounds---dark cells indicate high attention weight.
  \emph{Center:} Attention-augmented MLP matches baseline accuracy.
  \emph{Right:} Attention entropy peaks at 5 rounds (diffuse feature recruitment) and collapses at 7--8 rounds (noise).}
  \label{fig:attention}
\end{figure*}

Saliency analysis (\Cref{fig:saliency}) provides a direct answer to RQ1's ``which bits'' question.
On \speck at 5 rounds, the five most important input features are bits 14, 15, 30, 23, and 1.
Bits 14--15 correspond to the MSB of the XOR-difference channel ($C_L \oplus C'_L$); bits 28--30 lie in the analogous position of $C_R \oplus C'_R$.
This concentration on high-order difference bits confirms that the network detects truncated differential patterns in the penultimate round, as Benamira et al.~\citep{benamira2021deeper} hypothesized for Gohr's ResNet.

Attention analysis (\Cref{fig:attention}) reveals how signal \emph{density} varies with round count.
At 3 rounds, attention entropy is 7.1 bits (moderately focused on a few high-signal bits).
It rises to 9.0 bits at 5 rounds (the network recruits a broader feature set as signal weakens), then collapses at 7--8 rounds (accuracy $\approx$51\%, no signal to attend to).
This entropy trajectory provides a practical diagnostic: when attention entropy drops sharply, the distinguisher has exhausted the signal.

Combined with the representation ablation (R2\_xor\_diff dominates word-level inputs by 29\pp; \Cref{sec:app-ablations}), we can now answer RQ1 precisely:
\textbf{Signal resides in the XOR-difference bits of ciphertext pairs, concentrated at high-order positions, and is accessible to any architecture with sufficient capacity.}

\subsection{RQ2 Interpretation: Why Markov Composition Fails}
\label{sec:discussion-rq2}

The transfer results provide empirical evidence about \emph{what kind} of features neural distinguishers learn, directly testing the Markov assumption.

\paragraph{SPN (Markov-composable).}
Gohr et al.~\citep{gohr2022assessment} proved that under independent round keys, SPN distinguishers can only learn features captured by the DDT.
DDT features are hierarchical: the output distribution after $r$ rounds is a convolution of single-round DDTs, so patterns valid at $r$ rounds remain valid at $r' < r$.
Our \present results---99.1\% transfer from 4r to 2r---are fully consistent with Markov composition.

\paragraph{ARX (Markov-violating).}
For ARX ciphers, Gohr et al.~\citep{gohr2022assessment} showed that distinguishers learn non-differential features beyond the DDT, exploiting the interaction between modular addition and XOR.
These non-differential features produce round-specific correlations: a model trained at 5 rounds learns features that \emph{anti-correlate} with the 3-round distribution, producing 45.5\% accuracy.
This is a clean Markov violation: the learned representation does not decompose across rounds.

\paragraph{Feistel (unexpectedly Markov-violating).}
Gohr et al.'s theory predicts that Feistel distinguishers should learn only differential features, implying Markov composition.
Yet we observe anti-transfer: 48.6\% for \simon 6r$\to$4r ($p < 10^{-5}$).
We hypothesize that \simon's nonlinearity---bitwise AND between rotated copies of the state---creates differential patterns that, while technically within the DDT, are highly round-dependent due to the AND operation's asymmetric propagation.
Unlike \present's S-box, which achieves full diffusion within one round, \simon's Feistel structure requires multiple rounds for the AND-rotation patterns to stabilize, producing round-specific features that do not compose hierarchically.
Testing this hypothesis requires training on \simon with masked intermediate rounds, which we leave to future work.

\subsection{Key Recovery Failure: RQ1 $\cap$ RQ2}

\simon's 100\% distinguisher accuracy but 0\% key recovery lies at the intersection of both research questions.
RQ1 tells us that signal exists abundantly (100\% accuracy at 5r), but RQ2 tells us this signal is non-composable.
Gohr's Bayesian key search implicitly requires Markov decomposition: it assumes the $r$-round signal factors into an $(r{-}1)$-round signal plus a key-dependent last-round contribution.
When the signal is round-specific (anti-composable), this factorization fails, and the subkey ranking degenerates to random.

In \speck, the last round's modular addition creates a direct relationship between subkey errors and score changes, enabling partial decomposition.
In \simon, the subkey enters via XOR \emph{after} the nonlinear function $f(x) = (x \lll 1) \mathbin{\&} (x \lll 8) \oplus (x \lll 2)$, entangling subkey errors with the state through a complex nonlinear path.
Prior work achieves \simon key recovery through different means: Tian and Hu~\citep{tian2022simon} use prepended differentials with neutral bits, bypassing Bayesian search entirely.

\subsection{Limitations}

We acknowledge five limitations:

\begin{enumerate}[leftmargin=*,itemsep=1pt]
  \item \textbf{Architecture ceiling.} Our MLP achieves fewer rounds than published SOTA (7r \speck vs.\ 8r Gohr; 9r \simon vs.\ 11r DBitNet; 6r \present vs.\ 9r DBitNet). The ResNet comparison ($\leq$2.6\pp gap, ordering preserved) confirms the findings are architecture-independent.
  \item \textbf{Single input difference.} We use one $\Delta P$ per cipher. Evolutionary difference search~\citep{bellini2023dbitnet} may improve absolute accuracy by 5+\pp.
  \item \textbf{Single-pair setting.} Multi-pair aggregation ($n > 2$) consistently improves accuracy~\citep{zhang2025multipair}.
  \item \textbf{Classical baseline.} Our best-bit-bias is a single-bit distinguisher. A DDT-based multi-bit method~\citep{gohr2022assessment} would reduce the neural--classical gap in RQ1.
  \item \textbf{No PRESENT key recovery.} \present's 64-bit block requires a different partial decryption approach that we do not implement.
\end{enumerate}

\noindent
Critically, none of these limitations affect the RQ2 finding: transfer polarity depends on the source and target data distributions, not on the model's absolute accuracy or the input difference choice.
