\subsection{Cipher Implementation}

All cipher implementations follow the reference specifications:
\begin{itemize}[itemsep=1pt]
  \item \speck: 22 rounds, block 32 bits (two 16-bit words), key 64 bits (four 16-bit words), rotation constants $(\alpha, \beta) = (7, 2)$.
  \item \simon: 32 rounds, block 32 bits, key 64 bits, rotation constants $(1, 8, 2)$ in $f(x) = (x \lll 1) \mathbin{\&} (x \lll 8) \oplus (x \lll 2)$.
  \item \present: 31 rounds, block 64 bits, key 80 bits, 4-bit S-box + 64-bit permutation layer.
\end{itemize}

\subsection{Statistical Testing}

All $p$-values in \Cref{tab:transfer} are from two-sided one-sample $t$-tests against $\mu_0 = 0.5$, computed over $k \in \{3,5\}$ independent seeds.
Bootstrap 95\% confidence intervals in \Cref{tab:baseline} use 10,000 resamples.
We do not apply multiple-testing correction because each transfer experiment tests a distinct scientific hypothesis (different cipher--round pair).
