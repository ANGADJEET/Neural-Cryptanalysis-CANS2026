1 CRYPTOGRAPHIC SETUP
I picked SPECK32/64 [1] because Gohr [4] used it, enabling direct comparison. Its 32-bit block size keeps experiments
fast.
SPECK32 is an ARX cipher ΓÇö it uses only modular addition (Γè₧, i.e. (a +b) mod 216), bitwise rotation (Γë½/Γë¬), and
XOR (Γèò). The round function on two 16-bit words Li,Ri is:
Li+1 = ((Li Γë½7)Γè₧Ri)Γèòki
(1.1)
Ri+1 = (Ri Γë¬2)ΓèòLi+1
(1.2)
The Γè₧operation is critical: unlike XOR, modular addition produces carry propagation, which creates exploitable
differential bias. Constants ╬▒=7, ╬▓=2 are specific to the 32-bit variant. The full cipher runs 22 rounds; I test reduced-
round versions (3ΓÇô9 rounds).
Differential cryptanalysis [3]: pick a fixed XOR difference ΓêåP, encrypt (P,P ΓèòΓêåP) under the same key, and check
whether ΓêåC = Ek(P)ΓèòEk(P ΓèòΓêåP) looks non-random. Classical analysis assumes difference transitions are Markov:
P(ΓêåXi+1 | ΓêåXi,ΓêåXiΓêÆ1,...) = P(ΓêåXi+1 | ΓêåXi). I test this directly in E06 and E16.
I use GohrΓÇÖs input difference ΓêåP = 0x00400000 (bit 22). The ╬▒=7 rotation maps this bit into a carry chain through
the modular addition.
2 DATASET GENERATION
The pipeline (data/generator.py) generates N/2 positive and N/2 negative samples, verified against SPECK32 test
vectors, with deterministic seeds 42ΓÇô46.
Positives: draw random P Γêê{0,1}32, compute PΓÇ▓ = P ΓèòΓêåP, encrypt both under the same random key k: (C,C ΓÇ▓) =
(Ek(P),Ek(PΓÇ▓)).
Negatives: C and C ΓÇ▓ are independent random 32-bit integers. Strictly, a true random permutation ╧Ç would give
C = ╧Ç(P), C ΓÇ▓ = ╧Ç(P ΓèòΓêåP), which are not fully independent. For 32-bit outputs the distributions are statistically
indistinguishable in practice, but this approximation contributes to the accuracy gap versus GohrΓÇÖs setup (which uses
ciphertext pairs encrypted under different random keys).
Sizes: 5├ù105 training, 10% validation (early stopping, patience 5), 5├ù104 test. All results averaged over 5 seeds.

4 MODEL ARCHITECTURES
I implemented 7 architectures to test whether inductive bias matters for cryptanalysis, or whether any sufficiently
expressive model will do. Note: GohrΓÇÖs original 2019 architecture [4] was a deep residual network with convolutional
blocks and skip connections. My ΓÇ£ResNetΓÇ¥ is the closest to his design; the ΓÇ£Wide MLPΓÇ¥ is a separate, wider feedforward
baseline I built to isolate the contribution of residual connections.
MLP (32 ΓåÆ64 ΓåÆ64 ΓåÆ32 ΓåÆ1, ReLU, 191K params). The simplest baseline.
Wide MLP.1 A wider feedforward network (457K params) without residual connections. This serves as a capacity-
matched control for the ResNet: same parameter budget, no skip connections.
CNN. 1D convolutions over the bit vector (81K params). SPECKΓÇÖs rotations create shift-invariant patterns along the
bit axis, which convolutions can exploit.
ResNet. Residual blocks with Conv1D, BatchNorm, and skip connections (135K params). Closest to GohrΓÇÖs published
architecture, though smaller.
LSTM / GRU. Recurrent models that treat the bit vector as a sequence (594K / 454K params).
Siamese. Weight-shared sub-networks for C and C ΓÇ▓, classifying via embedding distance (57K params).
MINE. Mutual Information Neural Estimator [2]. Not a classifier ΓÇö used in E06 to compute I(C ΓèòC ΓÇ▓; Y ).
All models: Adam (╬╖ = 10ΓêÆ3, cosine decay to 10ΓêÆ4), batch size 5000, early stopping (patience 5).

5.1 E01: ACCURACY VS. ROUNDS
I trained a separate Wide-MLP distinguisher for each round count from 3 to 9 (Table 5.1, Figure 5.1). Accuracy drops
sharply between rounds 6 and 7 ΓÇö the ΓÇ£round cliff.ΓÇ¥ At 8+ rounds the model is indistinguishable from random guessing.
The qualitative shape of the round cliff matches GohrΓÇÖs published trend. However, my 5-round accuracy (87.4%) falls
short of GohrΓÇÖs reported Γê╝93%. This gap is expected: Gohr used a deeper residual network and a different negative-
sample construction (ciphertext pairs under a different random key, rather than independent random integers). My
negative class models two independent random functions, which is a standard approximation for 32-bit outputs but
not identical to GohrΓÇÖs setup.

5.3 E03ΓÇôE04: INVARIANCE AND ROBUSTNESS
E03 (Bit Permutation). Randomly permuting bit positions at test time drops accuracy from 87.1% to exactly 50.0%
(Figure 5.3), proving the model learns position-specific features, not generic statistics like Hamming weight.
Figure 5.3: E03: Accuracy collapses to 50% under bit permutation.
E04 (Noise Robustness). Bit flips are far more destructive than Gaussian noise: 1% bit-flip probability costs 3.1pp,
while ╧â = 0.05 Gaussian noise costs only 0.2pp (Figure 5.4). R2ΓÇÖs binary encoding absorbs sub-threshold Gaussian
perturbations harmlessly.
5.4 E05ΓÇôE06: CONTEXT DEPTH AND MARKOV VALIDATION
E05 (Memory Depth). I varied the number of consecutive intermediate round differences (white-box access) visible to
the network when targeting 7-round SPECK32 (Table 5.3, Figure 5.5).
Important caveat: E05 operates in a fundamentally different information setting than E01. In E01, the distinguisher
sees only the final ciphertext pair (black-box). In E05, it sees intermediate round outputs (white-box). This is why E05 at
depth 3 achieves 87.3% on 7-round SPECK32, while E01 at round 7 achieves only 50.7% ΓÇö the two experiments are not
directly comparable. E05 measures how many rounds of internal state the network needs to accumulate a detectable
signal, not whether the Markov assumption holds.

6 BONUS EXPERIMENTS: AUTOMATED DISCOVERY AND KEY RECOVERY
6.1 E10: NEURAL DIFFERENTIAL SEARCH
Instead of relying on the known-optimal ΓêåP, I swept 20 single- and multi-bit differences through the distinguisher at
round 5 (Figure 6.1).
The search correctly identifies ΓêåP = 0x00008000 (bit 15) as the best single-bit difference among those tested, at 76.2%,
far above the naive 0x00000001 (57.8%). However, this search did not rediscover the globally optimal difference:
GohrΓÇÖs ΓêåP = 0x00400000 (bit 22) achieves 86.4% at the same round (per E07). The reason is simply a coverage gap
ΓÇö my sweep tested only 20 candidate differences and bit 22 was not among them. Had it been included, it would
likely have ranked highest. This motivates E18: a smarter search strategy is needed to efficiently explore the full 32-bit
difference space.
6.2 E18: RL-BASED DIFFERENTIAL PATH DISCOVERY
I built a REINFORCE agent that starts from a random ΓêåP and flips bits to maximize the distinguisherΓÇÖs accuracy. At 3
rounds (Figure 6.2), the agent discovers 0x00102000 achieving 85.0%, approaching the known-optimal 86.6%. At 5
rounds, the reward landscape is too flat and the agent fails to converge.

6.3 E11: NEURAL VS. CLASSICAL SAMPLE-BASED ESTIMATION
I compared the neural distinguisher against a classical Dynamic Programming (DP) approach that empirically estimates
differential transition probabilities from samples (Figure 6.3).
Figure 6.3: E11: Sample-based classical DP estimation achieves 0% distinguishing accuracy.
The sample-based DP estimator fails at all round counts. This does not mean classical differential cryptanalysis is
inferior ΓÇö published analytical attacks on SPECK32 do exist and are effective [3]. What fails here is specifically empirical
probability estimation in a 32-bit output space: true differential probabilities are Γë¬2ΓêÆ16, requiring astronomically
more samples than I provide (5├ù105) to observe even a single transition. The neural network sidesteps this by learning
a nonlinear decision boundary over distributional features rather than tracking exact 232 ├ù232 transition counts. As
Gohr [4] noted, neural distinguishers complement rather than replace classical methods.

For 4-round targets, the true key ranks in the top 10 100% of the time, reducing the search space from 65,536 to

has genuine offensive utility for narrowing the key space.

propagates through bits 14ΓÇô15.

7.2 E09: CROSS-ROUND TRANSFER LEARNING
I tested whether a model trained on 5-round SPECK32 can distinguish other round counts zero-shot (Figure 7.3).
Figure 7.3: E09: Cross-round transfer. The 5-round model drops below random on 3ΓÇô4 rounds.
The model completely fails to transfer. At 6+ rounds, accuracy drops to chance ΓÇö the signal simply isnΓÇÖt there.
More interesting is the anti-transfer at 3ΓÇô4 rounds (45.5%, below random). This happens because the differential
signal at 3ΓÇô4 rounds is concentrated in different bit positions than at 5 rounds: the carry chain has not yet spread
as far, so the bit-14/15 features the 5-round model learned are not just uninformative but actively inverted on the
3-round distribution. The E08 saliency maps support this ΓÇö at different round depths, different bit positions dominate.
Zero-shot transfer to SIMON32 also fails (Γê╝45%), confirming that the learned features are cipher-specific and do not
generalize across different ARX structures. Every round-depth and every cipher requires a custom model.

7.3 E16: GENERATIVE MARKOV VALIDATION VIA VAE
I trained a conditional VAE to model how ciphertext differences evolve round-by-round. The encoder maps ΓêåCr to
a 16-dimensional latent space; the decoder predicts ΓêåCr+1. Both use 3-layer MLPs with 128 hidden units. I set ╬▓ = 1
(standard ELBO with equal reconstruction and KL weighting). I compare two settings: Markov (predict ΓêåCr+1 from ΓêåCr
alone) vs. Memory (predict from the full history ΓêåC1,...,ΓêåCr , implemented via an LSTM encoder).
(a) Latent space separates cipher from random at low rounds.
(b) Prediction error ratio (Memory/Markov) Γëê1.0 at all rounds.
Figure 7.4: E16: Generative VAE validates the Markov assumption.
The prediction error ratio sits at 1.0 through rounds 1ΓÇô4 (Figure 7.4b), meaning history provides no predictive benefit
over the current state. This directly validates the Markov cipher assumption for SPECK32. The latent space visualization
(Figure 7.4a) provides an independent confirmation: cipher differences cluster separately from random at low rounds
but converge as the signal decays.
